# NEON DISTRICT: REBOOT

Site fictif multi-pages au format interface de jeu vidéo, réalisé en HTML, CSS et JavaScript natifs.

## Mise en ligne sur GitHub Pages
1. Décompressez l'archive.
2. Importez **le contenu** du dossier `NEON-DISTRICT-REBOOT` à la racine d'un dépôt GitHub.
3. Dans le dépôt : **Settings → Pages**.
4. Choisissez **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis enregistrez.
5. Attendez la publication.

## Personnalisation
- Nom et textes : `index.html`
- Couleurs, mise en page et animations : `css/style.css` (variables au début du fichier)
- Navigation, chargement et sons synthétiques originaux : `js/app.js`

## Audio
Les bruitages sont générés en temps réel avec Web Audio API. Aucun fichier audio du jeu Cyberpunk 2077 n'est utilisé. Les navigateurs demandent une première interaction avant d'autoriser l'audio.

## Notes
- Aucun serveur ni framework nécessaire.
- Les pages sont des vues internes pour que GitHub Pages fonctionne sans configuration supplémentaire.
- Les visuels de ville, carte et véhicules sont dessinés en CSS.
